# Referencias

Las siguientes fuentes oficiales de AWS complementan los contenidos de [AWS Technical Essentials](index.md). La disponibilidad de servicios, sus características y sus precios pueden cambiar; consulta la documentación vigente antes de diseñar o desplegar una solución.

## Fundamentos de AWS e IAM

- [¿Qué es la computación en la nube?](https://aws.amazon.com/what-is-cloud-computing/){: target="_blank" rel="noopener noreferrer" } — conceptos y ventajas de la nube.
- [Infraestructura global de AWS](https://aws.amazon.com/about-aws/global-infrastructure/){: target="_blank" rel="noopener noreferrer" } — regiones, zonas de disponibilidad y ubicaciones de borde.
- [Modelo de responsabilidad compartida de AWS](https://aws.amazon.com/compliance/shared-responsibility-model/){: target="_blank" rel="noopener noreferrer" } — responsabilidades de AWS y del cliente.
- [¿Qué es IAM?](https://docs.aws.amazon.com/IAM/latest/UserGuide/introduction.html){: target="_blank" rel="noopener noreferrer" } — identidades, permisos y prácticas de administración de acceso.
- [Autenticación multifactor en AWS](https://docs.aws.amazon.com/IAM/latest/UserGuide/id_credentials_mfa.html){: target="_blank" rel="noopener noreferrer" } — configuración y uso de MFA.

## Redes

- [Grupos de seguridad de Amazon VPC](https://docs.aws.amazon.com/vpc/latest/userguide/vpc-security-groups.html){: target="_blank" rel="noopener noreferrer" } — control del tráfico de red mediante grupos de seguridad.
- [Network ACL de Amazon VPC](https://docs.aws.amazon.com/vpc/latest/userguide/vpc-network-acls.html){: target="_blank" rel="noopener noreferrer" } — reglas de tráfico a nivel de subred.
