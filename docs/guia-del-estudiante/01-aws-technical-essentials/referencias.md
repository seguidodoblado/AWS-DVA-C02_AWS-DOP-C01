# Referencias

Las siguientes fuentes oficiales de AWS complementan los contenidos de [AWS Technical Essentials](index.md). La disponibilidad de servicios, sus características y sus precios pueden cambiar; consulta la documentación vigente antes de diseñar o desplegar una solución.

## Fundamentos de AWS e IAM

- [¿Qué es la computación en la nube?](https://aws.amazon.com/what-is-cloud-computing/) — conceptos y ventajas de la nube.
- [Infraestructura global de AWS](https://aws.amazon.com/about-aws/global-infrastructure/) — regiones, zonas de disponibilidad y ubicaciones de borde.
- [Modelo de responsabilidad compartida de AWS](https://aws.amazon.com/compliance/shared-responsibility-model/) — responsabilidades de AWS y del cliente.
- [¿Qué es IAM?](https://docs.aws.amazon.com/IAM/latest/UserGuide/introduction.html) — identidades, permisos y prácticas de administración de acceso.
- [Autenticación multifactor en AWS](https://docs.aws.amazon.com/IAM/latest/UserGuide/id_credentials_mfa.html) — configuración y uso de MFA.

## Computación

- [Guía del usuario de Amazon EC2](https://docs.aws.amazon.com/AWSEC2/latest/UserGuide/concepts.html) — instancias, imágenes de máquina de Amazon (AMI) y conceptos de EC2.
- [Guía para desarrolladores de Amazon ECS](https://docs.aws.amazon.com/AmazonECS/latest/developerguide/Welcome.html) — ejecución y administración de contenedores.
- [Guía de usuario de Amazon EKS](https://docs.aws.amazon.com/eks/latest/userguide/what-is-eks.html) — Kubernetes administrado en AWS.
- [Guía para desarrolladores de AWS Lambda](https://docs.aws.amazon.com/lambda/latest/dg/welcome.html) — computación sin servidor y ejecución de funciones.

## Redes

- [Guía del usuario de Amazon VPC](https://docs.aws.amazon.com/vpc/latest/userguide/what-is-amazon-vpc.html) — VPC, subredes y conceptos de redes.
- [Grupos de seguridad de Amazon VPC](https://docs.aws.amazon.com/vpc/latest/userguide/vpc-security-groups.html) — control del tráfico de red mediante grupos de seguridad.
- [Network ACL de Amazon VPC](https://docs.aws.amazon.com/vpc/latest/userguide/vpc-network-acls.html) — reglas de tráfico a nivel de subred.
- [NAT Gateway](https://docs.aws.amazon.com/vpc/latest/userguide/vpc-nat-gateway.html) — acceso de salida a Internet desde subredes privadas.
- [AWS Site-to-Site VPN](https://docs.aws.amazon.com/vpn/latest/s2svpn/VPC_VPN.html) — conexión de una red local con una VPC.
- [AWS Direct Connect](https://docs.aws.amazon.com/directconnect/latest/UserGuide/Welcome.html) — conexiones de red dedicadas a AWS.

## Almacenamiento y bases de datos

- [Guía del usuario de Amazon S3](https://docs.aws.amazon.com/AmazonS3/latest/userguide/Welcome.html) — almacenamiento de objetos y buckets.
- [¿Qué es Amazon EBS?](https://docs.aws.amazon.com/ebs/latest/userguide/what-is-ebs.html) — almacenamiento en bloques para Amazon EC2.
- [¿Qué es Amazon EFS?](https://docs.aws.amazon.com/efs/latest/ug/whatisefs.html) — sistema de archivos elástico.
- [Amazon FSx](https://aws.amazon.com/fsx/) — opciones de sistemas de archivos administrados.
- [Guía del usuario de Amazon RDS](https://docs.aws.amazon.com/AmazonRDS/latest/UserGuide/Welcome.html) — bases de datos relacionales administradas.
- [Introducción a Amazon DynamoDB](https://docs.aws.amazon.com/amazondynamodb/latest/developerguide/Introduction.html) — base de datos NoSQL administrada.

## Monitorización, balanceo y escalado

- [¿Qué es Amazon CloudWatch?](https://docs.aws.amazon.com/AmazonCloudWatch/latest/monitoring/WhatIsCloudWatch.html) — métricas, alarmas y paneles de monitorización.
- [¿Qué es el balanceo de carga?](https://docs.aws.amazon.com/elasticloadbalancing/latest/userguide/what-is-load-balancing.html) — conceptos y funcionamiento de Elastic Load Balancing.
- [¿Qué es Amazon EC2 Auto Scaling?](https://docs.aws.amazon.com/autoscaling/ec2/userguide/what-is-amazon-ec2-auto-scaling.html) — ajuste automático de la capacidad de un grupo de instancias.

## Formación y certificación

- [AWS Training and Certification](https://aws.amazon.com/training/) — opciones de formación de AWS.
- [AWS Certification](https://aws.amazon.com/certification/) — certificaciones y guías de examen vigentes.
